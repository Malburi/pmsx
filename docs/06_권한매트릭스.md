# 06. 권한 매트릭스

- 문서 버전: v0.1 (2026-10-14)
- 권한 = **시스템 역할**(설치 전체) + **프로젝트 역할**(프로젝트별). 한 사용자가 프로젝트마다 다른 역할을 가질 수 있다.
- 표기: **A** 전체(등록·수정·삭제·승인) · **E** 등록·수정 · **O** 본인 담당 건만 등록·수정 · **R** 조회 · **–** 접근 불가

## 1. 역할 정의

| 구분 | 역할 | 설명 |
|---|---|---|
| 시스템 | SYS_ADMIN | 설치 관리자. 사용자·라이선스·공통코드·템플릿 |
| 시스템 | PMO | 전 프로젝트 조회, 대시보드·보고 |
| 프로젝트 | PM | 프로젝트 총괄, 승인권자 |
| 프로젝트 | PL | 파트 리더, 담당 파트 배분·검토 |
| 프로젝트 | ANALYST | As-Is 분석 담당 (SI 분석 단계) |
| 프로젝트 | DEV | 개발자 |
| 프로젝트 | QA | 테스트·품질 담당 |
| 프로젝트 | OPERATOR | SM 운영 담당 (SR 처리) |
| 프로젝트 | CUSTOMER | 고객 담당자 (게스트) |
| 프로젝트 | PARTNER | 협력사 인력 (게스트, 범위 제한) |

## 3. 데이터 범위 규칙
- 모든 조회는 **프로젝트 멤버십**으로 1차 필터 (PMO·SYS_ADMIN 제외).
- PARTNER는 프로젝트 설정의 **허용 시스템/메뉴** 범위 안에서만 As-Is 조회.
- 캡처 이미지·소스 스니펫 다운로드, 개인정보 포함 화면 조회는 감사 로그 기록 (NFR-SEC-003).
