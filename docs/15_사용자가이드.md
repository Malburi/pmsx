- 문서 버전: v1.0 (2026-10-15)
- 대상: PMS-X 1.0 사용자. 설치·운영은 `deploy/README.md` 와 설치 패키지의 `docs/설치가이드.md` 를 본다.

| 엑셀 | 대부분의 목록 화면 오른쪽 위 "엑셀 내보내기" / "가져오기". 고객사 양식은 관리 › 엑셀 템플릿 매핑에서 등록 |

## 1. 분석자 (ANALYST) — As-Is 화면 분석

1. **수집 결과 올리기**: As-Is 분석 › 수집 이력/업로드 → 수집기가 만든 `pmsx-<시스템>-<일시>.zip` 업로드. 회차별 변경(추가·삭제)과 실행 리포트를 볼 수 있다.
2. **화면 분석 뷰어**: 왼쪽 메뉴 트리에서 화면 선택 → 캡처 위 번호(핫스팟)를 클릭하면 오른쪽에 워크플로우(화면 → 함수 → API → 서버 → SQL → 테이블)가 나온다. 단계를 누르면 소스가 보인다.
   - 점선 연결 = 신뢰도 90% 미만 또는 미확정, 점선 핫스팟 = 소스에서 핸들러를 못 찾은 요소
   - "와이어프레임" 표시 화면은 실제 캡처가 아니라 소스 좌표로 그린 화면 → 필요하면 편집 모드에서 수동 캡처 업로드
3. **보정**: 화면 헤더 "편집 모드" → 빈 곳을 드래그해 요소 추가, 핫스팟 이동·크기 조절, 숨김. 워크플로우 단계의 ⋮ 메뉴로 연결 확정·기각·추가. 수동 보정은 재수집해도 유지된다.
4. **메모·상태**: 오른쪽 "메모" 탭에 업무 규칙 작성(Markdown). 화면 상태를 분석중 → 검토요청으로 바꾸면 PM·PL이 확정한다.
5. **테이블·ERD**: 테이블 정의서에서 주제영역·코멘트 정리, ERD에서 점선(추정 관계)을 확정/기각.
6. **산출물**: As-Is 분석 › 산출물 출력 → 화면정의서·프로그램 사양서(xlsx/pptx), 테이블 정의서·CRUD 매트릭스·인터페이스 목록(xlsx).

## 2. PM · PL

| 업무 | 화면 |
|---|---|
| 프로젝트 등록·멤버 | 관리 › 프로젝트 관리 (멤버 탭, 투입 체크리스트, 협력사 열람 범위) |
| WBS 만들기 | 일정 › WBS/간트 → "생성·가져오기" (방법론 템플릿 / 엑셀 / MS Project XML). 막대를 끌어 일정 변경, 크리티컬 패스·베이스라인 표시 |
| 베이스라인 | WBS 화면 "베이스라인 저장" → 일정 › 베이스라인 비교 |
| 인력 배분 | 인력·공수 › 투입 계획(월별 MM)·가용량 히트맵, 작업 배분(미배정 작업을 사람에게 끌어 놓기 — 100% 초과 시 경고) |
| 작업일지 승인 | 인력·공수 › 작업일지 › 승인함 |
| 주간보고 | 일정 › 주간보고 → "생성"(WBS·작업일지·이슈 자동 집계) → 총평 편집 → 제출 → 엑셀(고객사 양식) |
| 분석 진척 | As-Is 분석 › 분석 진척 현황 → 화면 다중 선택 → 담당 일괄 배정 |
| 품질 | 품질 › 이슈·리스크(5×5)·CR·테스트·결함·회의록 |
| 산출물 승인 | 산출물·추적성 › 산출물 대장 (승인 시 연결된 WBS 자동 완료) |
| 추적성 | 산출물·추적성 › 추적성 매트릭스 (화면 미연결·테스트 없음·실패·미해결 결함 강조) |
| 대시보드 | 홈 (PM / 고객 / 포트폴리오 보기) |
| SI → SM 전환 | 관리 › 프로젝트 관리 › SI 프로젝트 "인수인계" 마법사 → 시스템·멤버·옵션 선택 → 미리보기 → 실행 |

## 3. 개발자 (DEV) · QA

- 내 작업: 작업일지에 WBS/화면/SR 대상으로 시간 입력 → 주간 제출.
- 변경 영향 확인: As-Is 분석 › 영향도 분석 → 테이블(컬럼)·함수·API 선택 → 영향 화면·버튼·배치·최근 SR·담당자.
- 결함: 뷰어에서 핫스팟을 선택하고 "연결 이력" 탭 › 결함 등록 → 결함 화면에서 전이(배정 → 조치 완료 → 확인 → 종료).
- 테스트(QA): 품질 › 테스트 → 시나리오·케이스 작성 → 회차 생성 → 결과 입력(FAIL이면 결함 바로 생성).

## 4. 운영자 (OPERATOR) — SM

| 업무 | 화면 |
|---|---|
| SR 처리 | 운영(SM) › SR 목록/처리. SLA 칩(정상·임박·위반·일시정지) 확인 → 분류 → 배정 → 처리 중 → 해결. "화면 뷰어에서 보기"로 대상 화면의 워크플로우 확인. 유사 KB/SR 참고, 처리 후 KB 전환 |
| 장애 | 운영(SM) › 장애: 타임라인 기록, RCA·재발방지, 장애보고서 엑셀 |
| 반복 문제 | 운영(SM) › 문제: 후보 묶음(같은 화면·유사 제목 SR 3건 이상)에서 문제 등록 |
| 변경·배포 | 운영(SM) › 변경·배포: CAB 승인 → 배포 → 종료, 캘린더 |
| 정기 작업·자산 | 정기 작업 캘린더 체크, 운영 자산(인증서·라이선스 만료 D-day) |
| SLA | 운영(SM) › SLA 현황, 관리 › SLA 정책·업무 캘린더(공휴일은 공통코드 HOLIDAY) |
| 월간 운영보고 | 운영(SM) › 월간 운영보고 → 생성 → 편집 → 엑셀 |

## 5. 고객 (CUSTOMER)

- 로그인하면 **고객 SR 포털**로 이동한다.
- "새 요청" → 유형·제목·내용, 필요하면 대상 화면 선택 → 등록.
- 진행 상황과 담당자 답변(공개 코멘트)을 확인하고, 처리 완료 건은 "확인" 또는 "재요청".

## 7. 수집기 (현장 분석 PC)

```
pmsx-collector.exe init <소스루트>          # 화면/서버 기술 감지 → collector.yaml 초안
pmsx-collector.exe doctor -c collector.yaml # 브라우저·DB·URL·글꼴 등 점검
pmsx-collector.exe run -c collector.yaml [--incremental] [--no-capture]
pmsx-collector.exe upload --server https://pmsx.example --system HR --user analyst   # 비밀번호는 PMSX_UPLOAD_PW
```
- 테스트계에서만 캡처한다(운영계 주소는 `denyHosts`). 저장·삭제 같은 변경 요청은 기본으로 차단되고 리포트에 남는다.
- 지원 화면 기술: JSP/jQuery, Nexacro(N/14/17), XPlatform·MiPlatform, WebSquare, Vue/React, WinForms, ASP.NET WebForms/MVC. 서버: Spring(MyBatis/iBatis), .NET(ADO.NET/Dapper/EF). DB: Oracle·Tibero·PostgreSQL·MSSQL·MySQL 메타 수집.
