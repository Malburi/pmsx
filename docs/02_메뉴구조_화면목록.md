# 02. 메뉴 구조(IA) · 화면 목록

- 문서 버전: v0.1 (2026-10-14)
- 상단 GNB에서 **프로젝트를 선택**하면 좌측 LNB 메뉴가 해당 프로젝트 기준으로 바뀐다. 프로젝트 유형(SI/SM)에 따라 일부 메뉴가 숨겨진다.
