## 주요 리스크

| 리스크 | 영향 | 대응 |
|---|---|---|
| 레거시 화면 기술이 예상보다 다양/비표준 (자체 프레임워크, 문자열 조합 URL) | 매칭률 저하 | 동적 요청 관측을 1순위 근거로 삼고, 수동 보정 UX를 R1에 포함 |
| 테스트계 접속·계정 확보 지연 | 캡처 불가 | 수동 캡처 업로드 + 소스 좌표(Nexacro·WinForms) 기반 와이어프레임 대체 |
| 동적 캡처 중 데이터 변경 사고 | 신뢰 하락 | 변경성 요청 차단 기본값·위험 버튼 제외·운영계 차단·차단 내역 리포트 |
| 고객사 보안 정책으로 소스 반입 불가 | 스니펫 미표시 | 스니펫 미포함 옵션(구조·연결만 반입) |
| 4개 영역 동시 요구로 범위 팽창 | 일정 지연 | 릴리스 경계 고수, 파일럿 피드백은 다음 릴리스로 |
